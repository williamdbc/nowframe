# Release Notes — v1.9.0

Esta versão integra os controles nativos da janela à interface do Nowframe, removendo a barra de título separada sem perder os comportamentos esperados de cada sistema operacional.

## Novidades

- A janela do Nowframe agora incorpora os controles nativos de minimizar, maximizar e fechar ao conteúdo no Windows e Linux, além dos semáforos nativos no macOS.

## Melhorias

- Adicionada uma região global de arraste e reorganizados os controles dos temas para evitar sobreposição com os botões nativos da janela.

## Correções

- Nenhuma alteração.

## Infraestrutura e segurança

- A versão do pacote desktop foi sincronizada com `v1.9.0` para manter os artefatos de distribuição alinhados à release.

## Qualidade e documentação

- Adicionada cobertura automatizada para as configurações de janela específicas de macOS, Windows e Linux.
- A suíte completa foi validada com 297 testes em 63 arquivos, além de lint, typecheck e build de produção do Electron.

## Alterações importantes

- Nenhuma alteração.
