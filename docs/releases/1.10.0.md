# Release Notes — v1.10.0

Esta versão facilita a demonstração dos temas, ajusta os controles da interface e melhora a documentação para quem quiser configurar sua própria cópia do Nowframe.

## Novidades

- Adicionada uma demonstração automática dos temas pelo comando `demo:themes`, iniciada com F8 e interrompida com Esc.
- No macOS, a demonstração movimenta e clica com o cursor real do sistema para que os movimentos apareçam nas gravações de tela. Windows e Linux mantêm o cursor simulado.

## Melhorias

- Ajustadas as margens dos controles de conexão, temas, perfil e tela cheia, com distância lateral de 12 pixels.
- A demonstração começa imediatamente pelo próximo tema na ordem do menu, mantém cada tema visível por um segundo e restaura o tema inicial ao terminar. Depois de cada clique, o cursor permanece no ponto selecionado até a próxima troca.
- As posições dos botões são calculadas pela interface, sem depender de coordenadas fixas para uma resolução específica.

## Correções

- Padronizado o botão de sair da tela cheia no tema Setlist, removendo o visual quadrado e vermelho.

## Infraestrutura e segurança

- Adicionada a licença MIT ao código do projeto e aos metadados do aplicativo.
- O controle nativo do cursor é habilitado apenas em desenvolvimento pelo launcher de demonstração, aceita somente alvos dentro da janela remetente em foco e interrompe a automação quando a janela perde o foco.
- Atualizada a versão do aplicativo desktop para `1.10.0`.

## Qualidade e documentação

- README ampliado com criação do aplicativo no Spotify Dashboard, configuração de Client ID e callback, execução local e geração de builds.
- Adicionadas prévias dos temas Ambient, Spotlight, Minimalist e Lyrics, com perfil e nome do dispositivo ocultados.
- Documentadas as limitações de reprodução, letras, tracklists, APIs e distribuição dos builds.
- Removidos comentários desnecessários sem alteração intencional de comportamento.
- Adicionados testes para a demonstração dos temas, indisponibilidade de permissão do cursor e restrições do controlador nativo.

## Alterações importantes

- Cassette, Prism e Rocket League estão temporariamente ocultos no seletor de temas; suas implementações permanecem no projeto.
- A demonstração com cursor real no macOS exige Command Line Tools do Xcode e permissão de Acessibilidade. Ela não é ativada no desenvolvimento normal nem nos builds de produção.
- Para usar sua própria cópia, configure o Client ID do seu aplicativo Spotify no `.env.local`. O login usa PKCE e não requer Client Secret.
- A licença MIT se aplica ao código do projeto, não às capas, letras, marcas ou demais conteúdos de terceiros.
