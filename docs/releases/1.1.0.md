# Release Notes — v1.1.0

Esta versão torna o tema `Tracklist` mais natural para explorar e selecionar músicas, com navegação horizontal por arraste, inércia proporcional ao gesto e cliques confiáveis. Também atualiza a leitura de playlists para o formato atual da API do Spotify sem perder compatibilidade com o formato anterior.

## Novidades

- Adicionada navegação horizontal por arraste no carrossel do tema `Tracklist`, preservando o clique para reproduzir diretamente uma faixa.
- Adicionada inércia proporcional à velocidade do gesto, com desaceleração progressiva e interrupção ao iniciar uma nova interação.

## Melhorias

- O carrossel agora diferencia pequenos movimentos de um arraste real, mantém a navegação livre após a inércia e oferece feedback visual adequado durante o gesto.
- Imagens das capas deixam de iniciar o arraste nativo do navegador, mantendo o movimento concentrado no carrossel.

## Correções

- Atualizada a leitura das faixas de playlists para aceitar o campo `item` retornado pela API atual do Spotify, preservando temporariamente o suporte ao campo legado `track`.

## Infraestrutura e segurança

- Nenhuma alteração.

## Qualidade e documentação

- Adicionados testes para os formatos atual e legado de itens de playlist, além de cenários de clique, arraste e inércia do tema `Tracklist`.
